## 8. 章節節拍模板

### 8.1 三段結構（每章 ≥3000 字標準）

```
1. 開場（~300 字）：場景定位、上章殘留狀態、視角主體當下任務
2. 衝突（~600 字）：核心事件展開、決策與代價、版本／伏筆推進
3. 鉤子（~300 字）：留下倒數 / 新訊息 / 視角轉換點
```

### 8.2 每章建議寫的固定欄位（節拍格式）

```
- POV：[主視角]
- Event：[核心事件 1-2 句]
- Change：[狀態變化／能力／關係轉折]
- 推進的伏筆：[本章推進或埋設的 1-3 條]
- 關鍵限制：[本章不可做的事，禁忌清單]
```

### 8.3 反派視角短鏡頭（建議每 3-4 章一次）

模仿第五卷第三階段做法：每章不超過 100 字插入祁闕／審計司／更高層的鏡頭，建立因果鏈與壓迫感，但不喧賓奪主。

### 8.4 多視角章節節奏（模仿 Ch.175）

收束章可採用「多視角」結構：林燼／蘇嵐／祁闕／白扣／空白位置輪流出鏡，每人一段，最後在同一物理事件上交匯。
