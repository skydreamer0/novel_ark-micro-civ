## 核心世界觀（OS 隱喻）

- **母艦 Ark** = 封閉物理作業系統。氧氣、空間、重力 = 硬體資源。
- **存活點** = 低頻算力 (L-Compute)，維持肉體運行的貨幣。
- **信仰/信念** = 高頻算力 (H-Compute)，主機專用，用於規則覆寫。
- **規則碎片** = API 指令集，讓主角直接調用母艦底層代碼。
- **文明主機** = 高維度新 OS，寄生在母艦中運行。
- **審計司** = 系統的防火牆/防毒軟體。

### 成長雙線
- **外線（權限竊取）**：盜取管理員權限 → 身分提升、戰術模組
- **內線（代碼覆寫）**：文明用信仰計算 → 強行覆寫母艦物理規則
